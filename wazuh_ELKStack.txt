PHẦN 8: XỬ LÝ VÀ ỨNG PHÓ
Bước 8.1: Tạo Active Response (tự động block IP)
Trên Wazuh Server: sudo nano /var/ossec/etc/ossec.conf
Thêm vào cuối file (trước </ossec_config>):
xml
<command>
  <name>firewall-drop</name>
  <executable>firewall-drop</executable>
  <timeout_allowed>yes</timeout_allowed>
</command>

<active-response>
  <command>firewall-drop</command>
  <location>local</location>
  <rules_id>100100,100101,100102,100103</rules_id>
  <timeout>600</timeout>
</active-response>
Giải thích:

firewall-drop: Script block IP bằng iptables
rules_id: Khi phát hiện rule này, tự động block
timeout: Block trong 600 giây (10 phút)

Khởi động lại:
sudo systemctl restart wazuh-manager

Bước 8.2: Kiểm tra Active Response
Thực hiện lại tấn công từ Kali. Sau vài lần, IP Kali sẽ bị block.
Kiểm tra trên Target Server:

Bạn sẽ thấy rule DROP cho IP Kali.
